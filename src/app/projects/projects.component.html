Upwell Structure Monitor

Created December 2024

An online tool for monitoring in-game structures and fuel levels, used to plan the logsitcs in the game.
The application has a front-end built in Angular TypeScript, and a backend written in .NET 6. All data and tokens are stored client-side only.

Open Climber

Created spring 2023

Browser based application for climbing centers to allow their users to track their progress in the gym; keep high-scores and rate walls in the center.
The application also has an administration interface that allows the owners of the center to add, remove and modify walls and their attributes.
The application has a front-end built in Angular TypeScript, database management using Entity Framework and MSSQL; and a backend written in .NET 6.

Read more about the project on the Github!
